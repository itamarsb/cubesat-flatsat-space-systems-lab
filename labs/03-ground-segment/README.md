# S03 — Ground Support Equipment

**Situação:** Planejado.

## Objetivo

Construir o receptor de bancada e registrar os quadros enviados pelo simulador ou FlatSat.

## Escopo previsto

Rotina de ingestão; validação de integridade; logs e armazenamento; relatórios de quadros válidos e inválidos.

## Critério de conclusão

Receptor testado com dados conhecidos, incluindo casos de falha e recuperação.

## Execução e resultados

Ainda não há resultados experimentais validados publicados para este laboratório. As medições, o procedimento utilizado e as evidências serão acrescentados à medida que os testes forem realizados.

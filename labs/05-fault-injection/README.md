# S05 — Injeção controlada e diagnóstico de falhas

**Situação:** Planejado.

## Objetivo

Introduzir falhas de origem conhecida no emissor, no canal simulado ou no GSE e analisar os sinais disponíveis.

## Escopo previsto

Matriz de cenários; registro independente de falha; método de classificação; referências comparativas; análise de erros e casos indeterminados.

## Critério de conclusão

Ensaios reproduzidos, contagens por classe e limitações explicitadas.

## Execução e resultados

Ainda não há resultados experimentais validados publicados para este laboratório. As medições, o procedimento utilizado e as evidências serão acrescentados à medida que os testes forem realizados.

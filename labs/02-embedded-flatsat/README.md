# S02 — FlatSat com microcontrolador

**Situação:** Planejado.

## Objetivo

Implementar a geração de telemetria em hardware de bancada com STM32 ou plataforma equivalente.

## Escopo previsto

Firmware identificado; interface serial/USB; leituras reais ou simuladas rotuladas; capturas de recepção; comparação com casos de referência.

## Critério de conclusão

Comunicação repetível, formato validado e registros de medições disponíveis.

## Execução e resultados

Ainda não há resultados experimentais validados publicados para este laboratório. As medições, o procedimento utilizado e as evidências serão acrescentados à medida que os testes forem realizados.
